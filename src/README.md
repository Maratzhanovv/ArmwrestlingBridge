# Armwrestling Bridge Pattern

This project demonstrates the Bridge Design Pattern in Java.

# Abstraction
- Armwrestler
- AmateurArmwrestler
- ProfessionalArmwrestler

# Implementor
- TechniqueStyle
- TopRollTechnique
- HookTechnique
- PressTechnique

# Pattern idea
Armwrestler types and armwrestling techniques can change independently.
